本模块为仓库根级元数据集合，不包含业务代码：
- `README.md` 是平台的产品说明书与技术架构总览，按「用户权限→算力调度→在线开发→数据管理→模型训练→推理服务→监控→AIHub→大模型」九能力域展开，并给出 Kubernetes 底座、多集群/异构算力（NVIDIA/昇腾/寒武纪/海光/摩尔线程/沐曦）、RDMA/vGPU、ARM64 适配等整体技术定位。
- `LICENSE` 声明 MIT 开源协议。
- `.gitignore` / `.dockerignore` / `.qoderignore` 分别面向 Git、Docker 构建与 Qoder IDE 的忽略规则。
- `cube-studio.code-workspace` 将当前仓库与上游 `../label-studio` 作为 VS Code 双工作区打开，表明标注子系统以独立子仓库形式存在。
- `pytest.ini` 通过 `addopts = --basetemp=.pytest-tmp` 把 pytest 临时目录落到本地 `.pytest-tmp/`，规避 Windows 下系统临时目录符号链接清理导致的 PermissionError。
该模块不引入运行时依赖，仅承担仓库元信息、开发者环境与测试基线配置的职责。
